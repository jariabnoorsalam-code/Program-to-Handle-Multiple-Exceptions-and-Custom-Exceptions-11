# Program to Handle Multiple Exceptions and Custom Exceptions
## Practical No: 11
### Objective
To learn how to handle multiple exceptions and create custom exceptions in Python.
### Apparatus
- Computer or Laptop
- Python 3.x
- Visual Studio Code / Python IDLE
### Working Procedure
1. Open Python IDE.
2. Create a new Python file.
3. Write the exception handling program.
4. Use try, except and finally blocks.
5. Create a custom exception class.
6. Run the program and check the output.
### Source Code
The Python source code is available in `main.py`.
### Output
**Successful Execution:**
```text
Enter first number: 20
Enter second number: 5
Division Result: 4.0
Enter your age: 22
You are eligible.
Program execution completed.
```
**Zero Division Error:**
```text
Enter first number: 20
Enter second number: 0

```
**Custom Exception:**
```text
Enter first number: 20
Enter second number: 5
Division Result: 4.0
Enter your age: 15
Custom Exception: Age must be 18 or above!
Program execution completed.
```
### Conclusion
In this practical, I learned how to handle multiple exceptions and create custom exceptions using Python. I also learned the use of try, except, finally and raise statements.
